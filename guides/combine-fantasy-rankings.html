How to combine fantasy football rankings into one list

Rankings disagree, and no single source gets every week right. Titan's Import multiple sources averages several rankings into one list for the week, then makes every start/sit call in all your leagues from it.

Why combine rankings

An average smooths out any one source's misses, the same idea as the consensus rankings some sites publish. The difference is that you pick the sources, so the list is built only from the rankers you actually trust.

Step 1: Add your sources

  1. Open Titan and go to Rankings, then Import multiple.
  2. Pick the week.
  3. Add each source as a CSV file or a paste straight out of a spreadsheet, and give it a name, like Late-Round or FantasyPros. Every format the regular import reads works here.

A source can be more than one file. FantasyPros, for example, ranks one position per file: add the QB file as a new source, then add the FLEX, K and DST files to it. Each file fills in its own positions.

Step 2: Count the ones you trust more

Every source starts at 1x. Set any of them to 2x or 3x and it pulls the list its way. Titan remembers the weight by the source's name, so next week it's already set.

You can also count Titan's default rankings (Sleeper's weekly projections) as one more source, which is handy when you only have one or two lists of your own.

How the average works

  • Position by position. Each player's place at his position is averaged across the sources that rank that position.
  • Missing players count low. When a source leaves a player out, he counts just below that source's last player at his position. So a player only one list likes can't jump ahead of the ones everyone ranks.
  • One FLEX list. RB, WR and TE are fitted onto one overall list, the way your overall rankings (a FLEX file, or Late-Round's FLEX table) fit them together. That way a file that ranks only running backs still counts, without throwing off your FLEX calls.
  • Where they disagree. Every player shows his place in each source, and a split mark flags anyone the sources are 8 or more spots apart on.

Step 3: Save it and follow the calls

Save the combined list as that week's rankings. Lineups, game-day alerts and Results all use it, exactly as they would a single import. The sources are saved with it, so you can add one or change a weight later in the week, and if you sign in with Google it syncs to your other devices.

Only have one file? The regular import is quicker. See how to import your fantasy football rankings for the formats Titan reads.
